# Trilha DevSecOps - SACI 2026.2

Este repositório foi criado para armazenar e organizar as atividades desenvolvidas durante a trilha de **AppSec - DevSecOps** do processo de onboarding da **SACI 2026.2**.

O objetivo da trilha é aprender, na prática, como integrar segurança ao processo de desenvolvimento de software, aplicando conceitos de **DevSecOps** e **Shift-Left Security**. Ao longo das atividades, serão utilizadas ferramentas e técnicas para identificar vulnerabilidades no código, nas dependências e na infraestrutura da aplicação.

## Estrutura do Repositório

```text
.
├── app/
├── bloco1/
├── bloco2/
├── bloco3/
└── README.md
```

- **app/**: aplicação utilizada como projeto-alvo durante a trilha.
- **bloco1/**: atividades introdutórias e conceitos de segurança, incluindo SAST, DAST e SCA.
- **bloco2/**: implementação de uma pipeline de CI/CD com análise SAST utilizando Semgrep.
- **bloco3/**: evolução da pipeline com novos mecanismos de segurança, como análise de dependências, containers e detecção de segredos.

## Objetivo

Durante a trilha, o repositório será utilizado para acompanhar a evolução das atividades e documentar a construção de uma pipeline de desenvolvimento segura, adicionando verificações automáticas capazes de detectar vulnerabilidades antes que o código seja enviado para produção.

Entre os principais conceitos e ferramentas abordados estão:

- DevSecOps e Shift-Left Security;
- SAST, DAST e SCA;
- GitHub Actions;
- Semgrep;
- Trivy;
- Gitleaks;
- Docker;
- CI/CD;
- Deploy automatizado.
